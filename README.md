# 🎓 Dart OOP Fundamentals (Module 4 Assignment)

A beginner-friendly yet **well-structured Dart project** that demonstrates core **Object-Oriented Programming (OOP)** concepts including **class**, **constructor**, **inheritance**, and **abstraction**.

---

## 🚀 Project Overview

This project is a **simple console-based application** designed to showcase how OOP works in Dart through real-world-style examples.

It includes:

* Student information system
* Teacher inheritance model
* Shape abstraction with area calculation

---

## 🧠 Learning Objectives

This project was built to practice and demonstrate:

* Dart OOP fundamentals (Module 4)
* Class and object design
* Constructor usage
* Code reusability using inheritance
* Abstraction and encapsulation

---

## 📋 Features

### 1️⃣ Student Class

* Stores student **name** and **roll**
* Uses constructor for initialization
* Displays student info using a method

---

### 2️⃣ Inheritance (Person → Teacher)

* `Person` class defines common property: `name`
* `Teacher` class:
  * Inherits from `Person`
  * Adds `subject`
* Demonstrates **code reuse and hierarchy**

---

### 3️⃣ Abstraction (Shape → Circle)

* Abstract class `Shape`:
  * Contains abstract method `area()`
  * Uses **getter & setter** for controlled access
* `Circle` class:
  * Implements `Shape`
  * Calculates area using formula: πr²
